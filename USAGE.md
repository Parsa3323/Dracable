# Dracable Usage Guide

## Opening Dracable

Dracable is a browser-based calculator. Open `index.html` in a modern desktop or mobile browser. No installation or build process is required.

## Using the keypad

- Tap or click number buttons to enter numbers.
- Use `+`, `−`, `×`, or `÷` to select an arithmetic operation.
- Enter the next number, then press `=` to calculate.
- Use `AC` to clear the current calculation.
- Use the delete button to remove the last entered digit.
- Use `.` to enter a decimal number.
- Use `±` to switch the current number's sign.
- Use `%` to divide the current number by 100.
- Use `√x` to calculate the square root of the current number.
- Use `x²` to square the current number.

Division by zero and square roots of negative numbers display an error.

## Moving the calculator

Drag the calculator by its header area. The calculator follows the pointer while dragging.

## Minimizing and restoring

Select the minimize control in the header to collapse the calculator into a floating circular bubble. Drag the bubble to move it. Select the bubble to restore the calculator.

## Appearance

- Select the palette control to choose an accent color: blue, purple, emerald, rose, or amber.
- Select the sun/moon control to switch between light and dark appearance.

## Calculation history

Open the history panel with the history control in the header. Select a previous result to put it back into the display. Use **Clear** to clear the session's history, or close the panel to return to the calculator.

History is held in page memory and is not saved permanently. Reloading the page clears it.

## Keyboard controls

| Key | Action |
| --- | --- |
| `0`–`9` | Enter a digit |
| `.` | Decimal point |
| `+`, `-`, `*`, `/` | Choose an operator |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last digit |
| `Escape` or `C` | Clear |
| `%` | Percentage |

## Motion and accessibility

Button feedback and other motion effects respond to the browser's `prefers-reduced-motion` setting. Enable reduced motion in your operating system or browser accessibility settings to reduce supported animations.

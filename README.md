# Dracable

Dracable is a compact, draggable calculator widget built as a single-page web app.

> **Fully vibe-coded:** Dracable is fully vibe-coded. It is intended to be a clear example that vibe coding can produce a useful, polished, working application. The project embraces AI-assisted, conversational development as a legitimate way to turn an idea into a practical software output.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Percentage, square root, square, sign toggle, and decimal input
- Calculation history for the current session
- Light and dark appearance
- Five accent colors: blue, purple, emerald, rose, and amber
- Draggable floating calculator window
- Minimize to a movable floating bubble and restore it
- Mouse, touch, and keyboard input
- Button press feedback and ripple animation
- Reduced-motion support

## Run

No build step is required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Start calculating.

The page loads Tailwind CSS and Google Fonts from their CDNs, so an internet connection is needed for those external resources. The calculator itself is implemented in the page.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `0`–`9` | Enter a digit |
| `.` | Decimal point |
| `+`, `-`, `*`, `/` | Choose an operator |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last digit |
| `Escape` or `C` | Clear |
| `%` | Percentage |
